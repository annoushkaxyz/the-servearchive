# 3D pilot

One look, Naomi Osaka's red US Open 2025 dress, was turned into a 3D model to test whether the flat catalogue could become something you can turn around.

- **Input:** the finished front render and the inferred back render.
- **Model:** Hunyuan 3D v3.1 Pro image-to-3D, run on fal, with PBR materials and 100,000 faces.
- **Cost:** about $0.83 for the generation.
- **Web optimisation:** embedded textures resized from 4096 to 2048 px, so the file went from about 33 MB to 8.6 MB, with mesh and UVs unchanged.
- **Review:** the red two-tier bubble skirt and the hollow neck and armholes came through. Fit, interior and hidden construction are approximate, so it stays a pilot.
