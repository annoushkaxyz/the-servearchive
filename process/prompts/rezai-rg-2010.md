# Aravane Rezaï, Roland-Garros 2010: first-pass prompts

Two prompts, one for the front and one for the back. Each is sent with up to three images:

1. **Evidence:** a photograph of the player wearing the dress, here [Yann Caradec on Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Aravane_Rezai_Roland_Garros_2010_R1.jpg) (CC BY-SA 2.0).
2. **Style anchor:** an image used only for presentation (cloth realism, isolation, studio light), never for the design.
3. **Supporting detail:** a second photograph for close-up details, or, for the back, the newly generated front so materials and proportions match.

No photograph of the back was found, so the back is a conservative reconstruction from front and side evidence and is labelled as inferred on the site. The chest logo reads as "cheyda" with Persian script; the designer is not documented, so the site says so.
